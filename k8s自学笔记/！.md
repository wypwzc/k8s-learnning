### 一、架构与核心组件（必须脱口而出）

- **Master/Control Plane 组件**：API Server、Scheduler、Controller Manager、etcd 各自干什么
- **Node 组件**：kubelet、kube-proxy、Container Runtime 的作用
- **一个 Pod 从创建到运行的完整流程**（API Server → etcd → Scheduler → kubelet → 拉镜像、起容器）

### 二、核心资源对象（YAML 能写，字段含义清楚）

- **Pod**：多容器共享网络/存储、Init Container、健康检查（liveness/readiness probe）
- **Controller**：Deployment（滚动更新、回滚、副本控制）、StatefulSet（有状态应用）、DaemonSet、Job/CronJob
- **Service & Ingress**：ClusterIP/NodePort/LoadBalancer 区别、Ingress 基本规则写法、网络流转（Pod IP → Service Cluster IP → Endpoints）
- **ConfigMap / Secret**：如何挂载为环境变量或 Volume
- **Volume**：emptyDir、hostPath、PVC/PV 基本概念，静态/动态供给流程

### 三、网络与存储理解（能画简图）

- **Service 如何通过 kube-proxy（iptables/IPVS）实现负载均衡**
- **CNI 基本概念**（Flannel/Calico 等知道一种即可）
- **PV/PVC/StorageClass 绑定生命周期**：Provision → Bind → Use → Recycle/Delete

### 四、kubectl 常用命令（面试可能现场口述）

- 增删改查：`get / describe / logs / exec / apply / delete`
- 排错类：`describe pod` 看 Events，`logs` 查容器日志，`exec` 进容器调试，`top` 看资源
- 快捷操作：`scale` 扩缩容，`rollout undo` 回滚，`edit` 在线修改

### 五、调度与资源管理

- **调度流程**：预选 + 优选大致过程，nodeSelector/亲和性/反亲和性基本使用
- **资源限制**：requests 与 limits 区别，QoS 等级（Guaranteed/Burstable/BestEffort）
- **污点与容忍**：简单场景（比如让某些 Pod 只跑在指定节点）

### 六、基础排错思路（必问场景题）

典型题目：“Pod 一直 Pending / CrashLoopBackOff / ImagePullBackOff 怎么办？”

- 按链路排查：`describe pod` → 看 Events → 确认镜像、资源、PVC、Node 资源等
- Service 不通：检查 selector、端口映射、endpoints 是否正常 `get endpoints`
- DNS 问题：`exec` 进 Pod `nslookup` 测试，检查 CoreDNS

### 七、生态工具了解（加分但不硬性要求）

- **Helm**：知道基本概念（Chart、Release、Repo），能 `helm install` 部署应用
- **监控**：Prometheus + Grafana 的基本组件，知道 metrics-server 用于 HPA
- **日志**：EFK/Loki 简单架构
- **CI/CD 集成**：用 GitLab CI / Jenkins 把镜像推到仓库，再 `kubectl set image` 或 `helm upgrade`

### 八、面试常见问题举例

1. **Deployment 滚动更新过程**：如何保证服务不中断（maxSurge/maxUnavailable）
2. **Service 的 ClusterIP 是怎么实现的**（iptables/IPVS 规则）
3. **PV 和 PVC 的生命周期**（如何绑定、释放策略）
4. **如何让 Pod 调度到特定节点**（nodeSelector/affinity/taint）
5. **ConfigMap 热更新**（环境变量不更新，Volume 挂载文件会更新，但应用需 reload）
6. **查看某个容器的实时日志**（`kubectl logs -f <pod> -c <container>`）

### 学习路径建议

- **动手为王**：用 minikube / kind / k3s 本地搭建，把 Deployment、Service、Ingress、PVC 全手写 YAML 部署一遍
- **重点排错**：故意把镜像、端口、资源限制配错，练习看 Events 和日志定位
- **理解原理**：至少能画出“Pod 访问另一个 Service”的网络流图
- **面试话术**：强调“我在实验环境里遇到 xxx 问题，通过 describe/logs 排查出是 yyy，如何解决”，证明你有动手排查能力
